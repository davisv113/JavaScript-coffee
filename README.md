# JavaScript-coffee
A fórmula do café perfeito segundo meu pai Guilherme
https://davisv113.github.io/JavaScript-coffee/

## A fórmula

- **Pó de café:** 10% da água
- **Açúcar:** 8% da água

## Rodando local

Feito com Angular 21 + [angular-three](https://angularthree.netlify.app) (Three.js).

```bash
npm install
npm start
```

O deploy no GitHub Pages é automático a cada push na `main` (`.github/workflows/deploy.yml`).
